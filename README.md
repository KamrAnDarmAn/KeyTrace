# KeyTrace

A typing practice application to help improve your typing speed and accuracy.

## Features

- Real-time feedback on typing accuracy.
- Customizable word lists and difficulty levels.
- Progress tracking over time.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/KamrAnDarmAn/KeyTrace.git
   ```

2. Navigate to the project directory:

   ```bash
   cd KeyTrace
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## Usage

- Open your web browser and go to `http://localhost:3000`.
- Select your desired word list and difficulty level.
- Start typing and monitor your progress in real-time.
